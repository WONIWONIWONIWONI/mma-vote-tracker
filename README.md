# MMA TOP 6 — VOTE/TRACK

멜론 MMA 2026 TOP10 투표에서 현재 상위 6팀을 기록하는 비공식 트래커입니다.

- 1~6위 득표수와 공식 표시 득표율, 전체 표수 기준 점유율
- 시간 추이 그래프: 전체 6팀·팀 선택·세로 확대
- 표차 흐름 분석: 리센느 득표수 − 나머지 TOP6 팀별 득표수. 상대 순위순으로 5개 비교 선택지 제공
- 직전 관측 대비 변화, 시간별 증가량, 이미지·CSV 저장
- 원본 집계 시간이 제공되지 않아 조회 성공 시각(KST)을 사용합니다.
- 현재 상위 6위 밖의 팀은 저장하지 않습니다. 실제로 관측되지 않은 과거 데이터는 만들지 않습니다.
- 공식 공개 API: https://m2.melon.com/m6/mma/2026/vote/top10.json?lang=ko
- 서버에서 별도로 조회·저장합니다. 현재 예약 수집은 약 5분 간격을 목표로 합니다. GitHub Actions 실행 대기·원본 오류 시 보관 기록은 지연될 수 있습니다. PC를 켜둘 필요는 없습니다.
- 오류 시 마지막 정상값을 보존하고 오류 상태를 표시합니다.
- 공개 status API의 TOP10 종료 시각은 2026-10-29 23:59:59 KST입니다. 최종 확인 여유를 두고 10월 30일 00:10 KST 이후 수집을 종료합니다. 예약 실행은 이후 원본 요청 없이 종료됩니다.

GitHub Pages는 Actions로 화면을 배포하고, 사이트는 접속·수동 새로고침 때 멜론 공개 API를 직접 조회합니다. 자동 폴링하지 않습니다. 과거 기록 동기화는 동시에 별도로 진행하며 카드는 이를 기다리지 않습니다. 직접 관측은 브라우저 세션에만 유지되고 공용 저장소에는 쓰지 않습니다. 캔들 차트도 같은 데이터를 공유합니다.

검증:
- `node qa/test_axis.cjs`
- `node qa/test_hourly.cjs`
- `python -m unittest discover -s collector`

- `node qa/test_analytics.cjs` 회귀·음수 추격·양수 추격·확대/축소·관측 부족 검사.

## 조회 경로와 지연 (2026-10-15)
- raw.githubusercontent.com 응답에서 Cache-Control: max-age=300을 확인했습니다. 캐시 무효화 쿼리는 이미 있었지만 CDN·Actions 대기까지 실시간 보장하지는 못합니다.
- 기존 주 차트와 캔들 차트가 각각 10초마다 조회하던 중복 경로를 제거했습니다.
- 멜론 API가 사이트 Origin에 CORS를 허용함을 확인해 최신값을 직접 읽습니다. 10초 요청×6회 대신 요청 시 최신값 조회, 공용 이력은 별도 수집합니다.
- 직접 조회 실패/이력 동기화 실패/관측 나이를 별도로 표시합니다. 과거 이력 누락을 가짜 관측으로 채우지 않습니다.
- 장기적으로 공용 이력 지연도 줄이려면 상시 수집 서버+저장소와 짧은 캐시의 읽기 API가 필요합니다. 현재 GitHub Actions 스케줄의 시작 지연은 제거할 수 없습니다.

- 확대는 선택한 팀(기본 리센느)을 중심으로 시작하고, 배율 변경은 현재 중심을 유지합니다. 그래프 세로 드래그, 위아래 버튼, 위치 슬라이더로 이동합니다.


## 확대·이동과 이력 동기화 보완

- 멜론 최신 조회 버튼은 과거 이력 응답을 기다리지 않고 다시 사용할 수 있습니다. 진행 중인 이력 요청은 하나만 유지합니다.
- 공용 이력은 GitHub Contents API를 먼저 읽고 제한·실패 시 raw 주소로 대체합니다. 늦게 도착한 이력이 최신 직접 관측을 덮어쓰지 않습니다. 이력 마지막 시각도 지연 시 별도로 표시합니다.
- 득표수/점유율이나 기간을 바꿔도 확대 기준 팀을 다시 중심에 놓습니다. 시간축 2/4/8배 확대와 이전·이후 시간 버튼/슬라이더도 제공합니다. 두 축을 확대하면 그래프를 좌우·상하·대각선으로 드래그해 이동합니다. Ctrl+휠은 마우스 커서 주변 시간축을 확대합니다.
- 캔들 차트는 실제 그리기 영역과 커서/두 손가락 중간점을 기준으로 확대합니다. 핀치 시작 시점의 관측 위치를 유지하며 여러 번 움직여도 확대 중심이 누적 이동하지 않습니다.
- 캔들을 차트 폭 전체에 표시하고 PC 마우스 드래그, 확대·축소·전체 보기 버튼을 추가했습니다.
- 배포 전 `qa/test_ui.cjs`로 PC/모바일 실제 입력, 늦은 이력, 자동 요청 없음, 팀 색상, 양수/음수 격차 방향을 검사합니다. 배포 후 `qa/live_probe.cjs`로 실제 사이트에서 멜론 직접 조회와 세로 드래그를 확인합니다.

분석: 10월 15일 20:00~21:28 KST 보관 기록에는 2분 초과 수집 공백이 없었습니다. 수 분의 과거 기록이 한꺼번에 보인 현상은 원본 수집 간격만으로 설명되지 않으며 이력 전달 경로의 캐시·배포 지연과 구분해야 합니다. 이전 실행 로그에는 10초마다 수집·커밋한 기록이 있었고, 21:28 KST 확인 당시 60초 간격이었습니다. 이후 공용 이력은 짧은 예약 수집으로 전환되었습니다. GitHub Actions 예약 실행은 시작 지연을 보장할 수 없으므로 최신값을 멜론에서 직접 읽어 이력 전달 지연의 영향을 줄입니다. 공용 이력도 실시간 보장이 필요하면 상시 수집 서버·DB·짧은 캐시의 읽기 API로 이전하는 것이 후속 방안입니다.

- Ctrl+휠 확대·축소를 반복해도 양 끝 캔들 여백은 7px로 고정하고, SVG 밖으로 그려진 요소가 페이지 폭을 늘리지 않도록 제한합니다. 수집 커밋이 겹칠 때 JSON을 관측 시각별로 병합해 저장 충돌로 수집이 중단되는 문제도 처리합니다.

## 직접 조작과 예측 기간

- 주 차트의 기본 조회 기간은 24시간입니다.
- 그래프를 한 손가락/마우스로 잡고 좌우·상하로 이동합니다. 시간축 1배에서도 선택 기간보다 이전의 실제 기록으로 이동합니다. 위치 버튼·슬라이더를 없앴습니다.

- 예측선은 기본 30분이며 1·3·6·12·24시간을 선택합니다. 최근 60분의 추세를 해당 기간까지 연장한 조건부 추정으로, 장기 예측의 정확도를 보장하지 않습니다.
