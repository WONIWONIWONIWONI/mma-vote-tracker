# MMA TOP 6 — VOTE/TRACK

멜론 MMA 2026 TOP10 투표에서 현재 상위 6팀을 기록하는 비공식 트래커입니다.

- 1~6위 득표수와 공식 표시 득표율, 전체 표수 기준 점유율
- 시간 추이 그래프: 2~6위 확대 또는 전체 6팀 보기
- 표차 흐름 분석: 리센느 득표수 − 나머지 TOP6 팀별 득표수. 상대 순위순으로 5개 비교 선택지 제공
- 직전 관측 대비 변화, 시간별 증가량, 이미지·CSV 저장
- 원본 집계 시간이 제공되지 않아 조회 성공 시각(KST)을 사용합니다.
- 현재 상위 6위 밖의 팀은 저장하지 않습니다. 실제로 관측되지 않은 과거 데이터는 만들지 않습니다.
- 공식 공개 API: https://m2.melon.com/m6/mma/2026/vote/top10.json?lang=ko
- 공개 페이지의 TOP10 조회 주기와 같은 10초 간격으로 조회하고 분당 최신 관측 한 건을 보관합니다. GitHub Actions 실행 대기·원본 오류 시 갱신이 지연될 수 있습니다. PC를 켜둘 필요는 없습니다.
- 오류 시 마지막 정상값을 보존하고 오류 상태를 표시합니다.
- 공개 status API의 TOP10 종료 시각은 2026-10-29 23:59:59 KST입니다. 최종 확인 여유를 두고 10월 30일 00:10 KST 이후 수집을 종료합니다. 예약 실행은 이후 원본 요청 없이 종료됩니다.

GitHub Pages는 Actions로 화면을 배포하고, 사이트는 최신 데이터 파일을 10초마다 다시 확인합니다.

검증:
- `node qa/test_axis.cjs`
- `node qa/test_hourly.cjs`
- `python -m unittest discover -s collector`
