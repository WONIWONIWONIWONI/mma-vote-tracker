# VOTE/TRACK

[현재 MMA 트래커](https://woniwoniwoniwoni.github.io/mma-vote-tracker/) · [새 투표 연결 지침](docs/new-vote.md) · [구조와 검토 결과](docs/architecture.md)

멜론 MMA 2026 TOP10 상위 6팀을 추적하는 비공식 대시보드입니다. 현재 대회 화면과 여러 투표처용 공통 엔진·생성기를 함께 관리합니다. 빌드 없는 정적 사이트이며 `dist/`가 현재 사이트의 유지보수 원본입니다.

## 현재 동작

- 첫 접속·새로고침 때 멜론 공개 API를 직접 조회합니다. 자동 실시간 폴링은 없습니다. 수집기는 방문 여부와 무관하게 약 5분 간격으로 실제 관측을 기록합니다. Actions 실행·캐시·원본 장애로 이력은 늦을 수 있습니다.
- 순위 카드는 1·2위만 기본 표시하며, 더보기로 3~6위를 펼칩니다. 두 팀 기본 추이와 팀 토글, 드래그·핀치·Ctrl+휠, 5분/1시간/4시간/일봉, 1/4/24시간 추세, 날짜별·시간별 증가량, CSV/이미지를 제공합니다.
- 표차 상승은 빨강, 하락은 파랑입니다. 확대/축소 문구는 절대 격차 기준입니다. 팀의 과거 누락값을 0으로 채우지 않습니다.
- 날짜는 KST 00시 기준입니다. 정확한 경계 관측이 없으면 일부 구간으로 표시합니다. 자정 1분 이내의 첫 실제 관측은 인접 날짜가 같은 경계로 공유해 증가량 누락·중복을 방지하며 실제 시각을 유지합니다. 첫날은 둘째 날 00시의 누적 관측으로 복원합니다. 이후 날짜의 경계 누락과 무관하며, 첫 마감 관측에 없는 팀은 —로 표시합니다.
- 예측은 서버가 KST 00시·12시에 이후 **12시간**을 발행합니다. 과거 실제값만 학습하고 네 후보 모델을 완료된 12시간 오차로 검증합니다. 선택 기준은 `dist/gap-selector.js`에 있습니다.
- 예측 장부는 불변입니다. 현재 예측은 별도, 완료된 모든 예측은 하나의 누적 과거 그래프에 표시합니다. 최초 도입 전의 여섯 재현 기록도 보존돼 있습니다. 개인 localStorage 예측은 사용하지 않습니다.
- 기존 `top4` 필드명은 저장 호환성을 위해 유지합니다. 실제로는 최대 6팀입니다. 이 필드명을 데이터와 함께 일괄 변경하지 마세요.

## 개발 및 검증

Node 22 이상, Python 3.12 이상을 기준으로 합니다. Python 수집기는 표준 라이브러리만 사용합니다.

```sh
npm ci
npm run config                 # 설정 변경 후 실행
npm test                       # 설정 동기화 + 계산/수집/생성기 검사
npm run test:ui                # Playwright Chromium이 있는 환경: PC/모바일
npm run format                # 유지보수 원본 정렬; 데이터/복원 모델 제외
```

GitHub의 배포 작업에서 Chromium을 설치하고 UI 테스트를 실행합니다. 저장소의 수집 기록을 수정하는 명령을 테스트 목적으로 실행하지 마세요. 코드 PR은 데이터 파일을 포함하지 않으며, 수집기와 동시에 수정될 때도 실제 기록은 유지합니다.

## 다음 투표

다음에는 투표 링크를 전달하면 [새 투표 연결 지침](docs/new-vote.md)에 따라 공개 집계 경로·후보 ID·합산 규칙을 확인한 뒤 설정을 만들고 생성기를 실행하면 됩니다. 이미 확인된 응답 형태는 어댑터를 재사용하며, 다른 형태는 해당 원본 어댑터만 추가합니다.

```sh
node scripts/new-tracker.cjs --config confirmed-vote.json --out /empty/new-vote-tracker
```

생성 결과에는 빈 이력, 새 화면, 수집기, Pages 배포 워크플로가 포함됩니다. 다음 멜론 글로벌 MMA/베리즈의 **실제 연결은 아직 하지 않았습니다**. 검증용 `.example` 주소는 실제 API가 아닙니다. 다음 투표의 공개 링크와 공식 규칙을 확인하기 전에는 결과나 공식 합산 점수를 가정하지 않습니다.

이전 변경 설명은 [변경 이력](docs/change-history.md)에 보관했습니다. 거기의 옛 설명이 아니라 이 README와 현재 코드가 현행 동작의 기준입니다.

## 이미지 공유하기

상위 6팀 현황, 일반 추이, 캔들차트(페이스 분석 제외), 12시간 표차 예측, 하루 증가량(과거 기록표 제외), 시간대별 증가량의 여섯 곳에 `이미지 공유하기`를 제공합니다. 각 공유창에는 세 가지 작업만 있습니다.

- `이미지 복사`: 복사 시점의 PNG를 클립보드에 넣습니다.
- `PNG 다운로드`: 같은 PNG를 파일로 저장합니다.
- `HTML 공유`: 이미지 없이 구성한 게시판용 HTML을 복사합니다.

이미지 주소 입력, 주소 HTML 복사, HTML 파일 저장과 패널 바깥의 중복 이미지 다운로드 버튼은 제거했습니다. PNG 기능과 데이터·예측 기록은 유지합니다. 공유창에 이미지와 HTML 준비 상태, HTML 글자 수를 표시합니다.

HTML은 정상 문서 흐름과 표로 배치합니다. 위치 지정·좌표·transform·clip-path·flex·grid를 게시판에 전달하지 않습니다. 순위 카드는 일반 표의 셀 안에 글자와 수치를 함께 넣으므로 위치 지정 CSS가 제거되어도 빈 배경과 글자가 따로 흘러가지 않습니다. 시간대별 표는 선택 날짜 전체를 포함합니다.

꺾은선·캔들·예측 그래프는 현재 선택 구간을 작은 색상 표 셀로 간략 표현합니다. PNG처럼 원본 선과 글꼴을 픽셀 단위로 보존하는 방식은 아니며, 좁은 선이나 촘촘한 캔들은 합쳐 보일 수 있습니다. HTML의 수치와 텍스트는 원본 그대로 유지합니다. HTML이 길면 표 그래프의 격자를 낮춰 용량을 줄이며 65,535자 이내일 때만 복사할 수 있습니다.

검증은 PC·모바일의 여섯 패널, 복사·다운로드, 글자 수, 그리고 위치·변환·클리핑·flex/grid 등의 CSS를 제거한 상황을 포함합니다. 실제 디시 게시글 등록과 실제 필터 전체는 검증하지 않았습니다. 게시판의 글꼴·여백·색상 처리에 따라 모양이 달라질 수 있습니다.

PNG 캡처는 브라우저 안에서 외부 폰트 내장을 건너뛰고 시스템 글꼴로 처리합니다. 일반 캡처는 최대 1.5배 해상도이며 동일한 화면은 최근 결과를 재사용합니다. 이미지 클립보드는 브라우저·게시판의 지원이 필요하며, 실패하면 PNG 다운로드·첨부를 안내합니다. 외부 업로드는 하지 않습니다. 캡처 라이브러리 html-to-image 1.11.13과 MIT 라이선스는 `dist/vendor/`에 보관합니다.

### 게시판의 색상·셀 기본값 대응

모든 공유 HTML의 숫자·시간·보조 문구에 글자색을 직접 지정하고, 어두운 중성 글자는 밝은 색으로 올립니다. 부모의 글자색 상속이나 `font color` 속성에만 의존하지 않습니다. 기존 `bgcolor`가 제거되어도 유지되도록 배경색을 인라인 CSS에도 넣습니다.

그래프는 각 표 셀에 인라인 배경색·0 여백·1px 글자/줄 높이와 비어 있지 않은 영폭 문자를 넣습니다. 게시판이 배경색 속성을 제거하거나 td·굵은 글자에 어두운 글자색과 큰 여백을 적용한 조건으로도 선의 색·너비·높이를 검사합니다. 이 조건은 사용자 캡처에 나타난 실패를 재현하기 위한 것이며 실제 디시 필터 전체를 확인한 것은 아닙니다.

붙여넣기 가이드라인 중 HTML 조각·인라인 CSS·표 기반 배치·배경색 이중 지정·가변 너비를 적용합니다. 기존 디자인이 우선이므로 어두운 배경과 팀별 색상을 유지합니다. 글자 전용 font/small/h2/th 요소는 span/div/td로 바꾸며, 그래프의 열 너비를 유지하는 표 구조는 보존합니다. 시간대별 표의 고정 최소 너비를 없애고 줄바꿈을 허용하며 설명 문구는 12px 이상으로 표시합니다. 표와 셀의 배경은 bgcolor와 인라인 background-color에 함께 넣습니다.
